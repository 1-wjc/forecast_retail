# 개발 과정

2024년 9월 24일 데이터를 받은 뒤 10월 18일 예선 답안을 제출하고, 11월 1일 본선 자료 제출, 11월 6일 본선 발표까지 진행함.

## 단계별 흐름

| 단계 | 기간 | 무엇을, 왜 바꿨나 |
|---|---|---|
| 데이터 확인·판매 추이 탐색 (v0.1) | 2024.09.24~10.15 | 거래 데이터에서 목표 상품군(데이터 1 중분류 `라면,통조림,상온즉석`, 데이터 2 대분류 `면류.라면류`)을 뽑아 일별·월별 판매 추이를 R로 확인함. 매출과 반품이 1:1로 맞지 않아 월별 매출 수량에서 반품 수량을 빼 순판매량으로 정의함. ARIMA도 시험했으나 36개월 시계열만으로는 외부 요인을 반영하기 어려워 외부 변수를 넣는 회귀형 모델로 방향을 정함. |
| 외부 변수 수집·선택 | 2024.10.08~10.15 | 소비자물가지수·라면물가지수·코로나 확진자, 소비자심리·경제심리지수·음식료품판매액, 네이버·구글·카카오·유튜브 검색 트렌드를 모음. 순판매량과 상관관계를 확인해 데이터 1은 음식료품판매액·유튜브트렌드·소비자물가지수, 데이터 2는 네이버트렌드·경제심리지수를 고르고 월 더미 11개를 더함. |
| 모델 비교, 무작위 분할 (v0.2) | 2024.10.16~10.17 | 선형 회귀·RandomForest·GradientBoosting·XGBoost를 무작위 분할로 비교하고 변수 중요도를 확인함. |
| 날짜 기준 평가·튜닝 (v0.3) | 2024.10.17~10.18 | 예측 대상이 미래 기간이므로 2021~2022년 학습, 2023년 평가로 바꿔 모델을 다시 비교함. 데이터 1은 CatBoost를 GridSearchCV 27개 조합으로 튜닝하고, 데이터 2는 MLP를 추가해 비교함. |
| 예선 답안 제출 | 2024.10.18 | 2021~2023년 데이터로 다시 학습해 2024년 1~6월 월별 순판매량을 예측하고 답안을 제출함. |
| 본선 자료 (v1.0) | 2024.10.19~11.06 | 최종 모델 코드를 정리하고 보고서용 그림을 R로 만듦. 데이터 1 비교 모델 중 GradientBoosting·RandomForest·XGBoost는 `random_state`가 없어 실행마다 MAE가 달라지며, 보고서의 값(753.30, 1,084.21)과 저장소 노트북 출력(1,206.34, 873.86)은 서로 다른 실행 결과임. 어느 실행에서도 CatBoost(658.54)가 가장 낮음. 분석 보고서와 발표 자료를 준비해 11월 1일 제출하고 11월 6일 발표함. 우수상 수상. |
